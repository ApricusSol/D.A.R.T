Why python for all of this?
- Lots of libraries $ built in data handling (dynamic timestamps, file path construction, logging are all handled by native libraries)
- Native modules manage mixed-privilege execution, checking os.geteuid() to enforce root access for network commands while using environment variables to launch Wireshark can be done as a standard user
- Simpler modular upgrades like argparse for passing in interface names, channels, or capture files directly into the command line
- subprocess module provides control over background applications
